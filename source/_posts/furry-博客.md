### 我咋做这个页面的

很简单, 
首先, 下载 **node**, 然后依次运行

```bash
npm install -g hexo-cli
hexo init furry
cd furry
pnpm install
hexo server
hexo new "furry 博客"
```

然后就有这个页面了
