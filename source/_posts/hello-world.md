欢迎来到 [Hexo](https://hexo.io/)!
这是你的第一条帖子. 
查看[文档](https://hexo.io/docs/)以获得更多信息. 
如果在使用 Hexo 时遇到任何问题, 
你可以再[故障排除](https://hexo.io/docs/troubleshooting.html)中获得答案, 
或者你可以再 [GitHub](https://github.com/hexojs/hexo/issues) 上问我.

## 快速开始

### 新建一条帖子
``` bash
$ hexo new "My New Post"
```

更多请参见: [写作](https://hexo.io/docs/writing.html)

### 运行服务器

``` bash
$ hexo server
```

更多请参见: [服务器](https://hexo.io/docs/server.html)
### 生成静态文件

``` bash
$ hexo generate
```

更多请参见: [生成](https://hexo.io/docs/generating.html)

### 部署远程站点

``` bash
$ hexo deploy
```

更多请参见: [部署](https://hexo.io/docs/one-command-deployment.html)
