“学术垃圾聚集地”服务器

我开了一个MC服务器, 来玩一玩~

本文章仅作友情推广, 并非大众宣传. 如果你偶然看到本页, 请忽视.

服务器ip?

play.simpfun.cn:27847

看出来了, 是用简幻欢开的公益服, 注意限制20个人, 不要超员了哦.

游戏版本?

用的是 喷泉互通服 哦~ 具体版本是 Java 版 1.21.11 或者 国际基岩版 26.0. 使用 Java 1.10 ~ 1.21.11 或者 BE 1.21.13X ~ 26.0 都可以呢~ (向下兼容, 向上兼容未经测试, 不提供支持).
